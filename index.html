      Altiguard Kernel v7.0 // Architecture & Credits

      COETA Worker Monitoring & Tactical Command is a real-time industrial IoT spatial elevation, geofence perimeter, and kinematic fall-detection platform engineered by Vaibhav Raju Kondane.

      Node.js & Express Socket.IO Real-Time Mesh 3D Isometric Digital Twin Leaflet GIS & Overpass Radar Open-Meteo Weather & AQI Web Audio & AI Speech Synthesis

      1. Spatial Z-Axis Matrix

      Tracks worker floor levels relative to a calibrated Structural Datum Zero with 2D stick-figure telemetry and a 3D isometric building twin.

      2. Kinematic Fall Physics

      Monitors sliding time-window vertical displacement (ΔZ/Δt) to detect freefalls and trigger instant acoustic, voice, and Ntfy.sh push alerts.

      3. Geofence Perimeter

      Computes Haversine perimeter distance from Command Admin and queries OpenStreetMap Overpass API for nearby emergency response centers.

      4. Hybrid GitHub Deployment

      Runs both as a full-stack Node.js + Socket.IO server AND serverless on GitHub Pages with autonomous elevation patrol simulation.
